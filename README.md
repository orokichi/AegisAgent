# AegisAgent

Androidのユーザー補助機能（AccessibilityService）と Groq Console API を組み合わせた、安全保護装置・緊急停止システム付きの自律型AIエージェントアプリです。

## 主な機能
- **強力なセキュリティセーブ装置 (`SafetyGuard`)**: 金融・決済アプリ、パスワード欄、システム設定・初期化・アンインストールを自動ブロックし、送信・購入・削除などの危険操作は実行前に一時停止して承認を求めます。
- **いつでも停止できるシステム**: 最前面のフローティング「緊急停止 STOP」ボタン、常駐通知の停止ボタン、画面オフ時の自動緊急停止を搭載。
- **定期タスク実行**: 指定した時間帯・曜日に自律タスクを自動起動（画面ロック中は安全スキップ）。
- **Material 3 Expressive + Dynamic Color**: 端末の壁紙カラーに連動するモダンなUI。
